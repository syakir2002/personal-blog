How I Built a Rule-Based Decision Support System for My FYP (UniVent System)

For my university Final Year Project (FYP), I wanted to tackle a problem every student organization faces: the slow, fragmented process of booking campus venues and managing student events. My solution was the UniVent System, a centralized platform built using PHP (CodeIgniter) and Bootstrap 5. However, the core heart of this system wasn't just data entry—it was its Decision Support System (DSS).

The Problem: Administrative Overload

Traditionally, when an event organizer submits a venue booking request, administrators must manually look over rules: Is the venue available? Does this event match the venue capacity rules? Does the organizing club have the appropriate clearance? This manual review causes massive delays.

The Solution: Mapping Out the Rules

To eliminate this bottleneck, I structured a rule-based pipeline where the organizer initiates a booking, and the backend automatically evaluates constraints before pushing it to administrators for absolute final approval. The core system functions on deterministic IF-THEN computational pathways:

IF Venue_Status == Available
AND Event_Expected_Attendance <= Venue_Max_Capacity
AND Clash_Detected == False
THEN Set Request_Status = "Auto-Validated; Pending Admin Approval"

The Outcome

By enforcing this rule-based filtering framework at the data entry point, the system instantly catches conflicting duplicate requests. It shifted the administrator's role from manual cross-referencing to a simple one-click verification system, drastically improving efficiency on campus.
