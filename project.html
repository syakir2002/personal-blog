UniVent System (On Going)

UniVent System is a university event management platform developed as my Final Year Project (FYP) to improve how students discover and engage with campus events. The system provides a centralized platform where students can easily browse upcoming events, view event details, and leave comments through a mobile application developed using Flutter. In addition, administrators can manage event information and monitor user interactions through a web-based system built with CodeIgniter 4 and Bootstrap 5. This project allowed me to gain experience in full-stack development, REST API integration, database management, and user interface design while creating a practical solution that enhances communication and participation within the university community.

Role: Full Stack Developer
Duration: 2025 - 2026
Platform: Mobile & Web
Team Size: 1 Person
