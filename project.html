UniVent System (On Going)

UniVent System is a university event management platform developed as my Final Year Project (FYP) to improve how students discover and engage with campus events. The system provides a centralized platform where students can easily browse upcoming events, view event details, and leave comments through a mobile application developed using Flutter. In addition, administrators can manage event information and monitor user interactions through a web-based system built with CodeIgniter 4 and Bootstrap 5. This project allowed me to gain experience in full-stack development, REST API integration, database management, and user interface design while creating a practical solution that enhances communication and participation within the university community.

Rental House System

Rental House System is a web-based property management platform developed to simplify the process of managing rental houses for both property owners and tenants. The system enables users to browse available rental properties, view detailed house information, and submit rental inquiries through a user-friendly interface. Property owners can manage property listings, update rental information, and monitor tenant requests efficiently through an administrative dashboard. Developed using CodeIgniter 4, Bootstrap 5, and MySQL, this project enhanced my skills in full-stack web development, database management, user authentication, and responsive user interface design while providing a practical solution for rental property management.

Role: Full Stack Developer
Duration: 2025
Platform: Web Application
Team Size: 1 Person
Status: Completed
PHP CodeIgniter 4 Bootstrap 5 MySQL MVC Architecture Responsive Design

Infrastructure Monitor

Infrastructure Monitor is a system monitoring project designed to track server performance and detect potential resource issues in real time. The project utilizes Prometheus for metrics collection and Grafana for data visualization, enabling administrators to monitor CPU usage, memory consumption, and overall system health through interactive dashboards. To evaluate monitoring effectiveness, CPU and memory stress tests were performed under different workload conditions, while automated email alerts were configured to notify administrators whenever predefined resource thresholds were exceeded. This project enhanced my understanding of Linux system administration, performance monitoring, alert management, and infrastructure reliability.

Role: System Administrator
Duration: 2025
Platform: Linux Server
Team Size: 1 Person
Status: Completed
Prometheus Grafana Linux Monitoring Alerting DevOps
